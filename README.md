# E-Commerce Sales Analytics | Power BI & SQL

## Project Overview
Developed an interactive E-Commerce Sales Analytics dashboard using Power BI and SQL to analyze sales performance, customer behavior, product performance, and order trends.

## Tools & Technologies
- Power BI Desktop
- SQL
- DAX
- Power Query
- Data Modeling

## Dataset
- 2,000 Orders
- 90 Customers
- 38 Products
- 4,967 Order Items

## Dashboard Pages
1. **Executive Overview** — Revenue, orders, customers, sales trends, and category performance.
2. **Product Analysis** — Product revenue, top-selling products, quantity sold, and category performance.
3. **Customer Analysis** — Customer distribution, top customers, order value, and inactive customers.
4. **Order Analysis** — Order status, cancellations, daily sales, and order KPIs.

## Key Features
- Interactive filters for month, category, city, gender, and order status.
- SQL queries for business analysis, including joins, aggregations, CTEs, and window functions.
- DAX measures for key performance indicators.
- Interactive charts, KPI cards, and navigation between dashboard pages.

## Project Files
- `e_commerce_project.pbix` — Power BI dashboard
- `E-Commerce Sales Analytics.sql` — SQL business analysis queries

## How to Use
1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the dashboard pages and interact with filters.

*This is a portfolio project based on a sample e-commerce dataset.*
